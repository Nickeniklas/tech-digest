GitHub Releases a Toolkit for Writing Specs Before Code

GitHub published spec-kit, a toolkit for Spec-Driven Development — a workflow where you write a clear specification before any code is written, so AI tools and developers build from the same plan. For teams that collaborate with developers or manage software projects, this signals a shift in how AI coding tools are being directed.

A New AI Voice Tool Runs Fast, On Your Device, in Many Languages

Supertone released supertonic, a text-to-speech engine that runs natively on your device via ONNX — no cloud connection required, no data sent to a server. It supports multiple languages and is built for speed. For anyone creating audio content, accessibility tools, or multilingual presentations, this is a private and fast alternative to cloud-based voice services.

Superpowers: An Agentic Framework That Includes a Working Methodology

A developer released Superpowers on GitHub — a framework that packages AI agent skills alongside a structured software development methodology. Unlike most toolkits that hand you building blocks, Superpowers tries to provide a complete, repeatable process for how AI agents should approach complex engineering tasks.

ApproachRaw ToolkitSuperpowers

Why it matters

Most AI agent frameworks give developers raw capabilities; Superpowers adds a layer of structure — a set of principles for when and how the agent should act at each stage of a project. For teams trying to make AI coding agents more predictable and reliable, this approach is worth watching. It's similar in spirit to test-driven development: not a new tool, but a discipline layered on top of existing tools.

3D Reconstruction for Everyone: Brush Brings Gaussian Splats to Any Platform

ArthurBrussee released Brush on GitHub — an open-source 3D reconstruction tool that turns photos or video into navigable 3D scenes using a technique called Gaussian Splatting. It is designed to run on a wide range of hardware, not just high-end workstations.

FeatureBrush
InputPhotos or video
OutputNavigable 3D scene
TechniqueGaussian Splatting
Hardware requirementBroad compatibility
LicenseOpen source
Why it matters

Gaussian Splatting has been one of the fastest-growing techniques in 3D capture because it produces photorealistic results from ordinary camera footage. Making it accessible on more hardware means architects, designers, real-estate professionals, and educators can capture and share 3D environments without expensive equipment. Brush is the latest signal that this capability is moving from research labs to everyday tools.
