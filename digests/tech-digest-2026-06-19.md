## A New Open AI Model, GLM-5, Aims to Replace 'Vibe Coding' With Real Engineering

**What happened**
Z.ai released GLM-5, a new large language model published as open-source on GitHub, pitched as a step up from quick, unstructured AI coding sessions toward more reliable, structured software development.

**What this means**
If your team uses AI coding assistants, expect more competition among open models, which usually means cheaper, more capable tools reach you faster. It's also a sign AI builders are shifting focus from flashy demos to dependable, production-ready work.

## Quick Hits

### A New AI Model Generates Matching Video and Audio Together

Lightricks released LTX-2, an open-source AI model that creates video and matching audio from a single prompt, plus tools to fine-tune it for specific styles. For marketers and designers, it's another sign that AI-made video content is getting easier to produce in-house.

Source: [GitHub ↗](https://github.com/Lightricks/LTX-2)

### An All-in-One Platform for AI Coding Agents Is Trending on GitHub

Kilo Code bills itself as an all-in-one platform for building and running AI coding agents, bundling several tools developers currently juggle separately into one workflow. It reflects a broader trend of teams consolidating AI coding tools rather than running many at once.

Source: [GitHub ↗](https://github.com/Kilo-Org/kilocode)

### A New Tool Turns Messy Documents Into Searchable Knowledge Maps

Hyper-Extract is a free tool that uses AI to convert unstructured text, like contracts, reports, or research papers, into structured graphs and timelines with a single command. That could help anyone who needs to make sense of large piles of documents, from researchers to lawyers.

Source: [GitHub ↗](https://github.com/yifanfeng97/Hyper-Extract)

## Under the Hood

### The Team Behind Astro Is Building a 'Sandbox' Framework for AI Agents

**What happened**
Flue, from the makers of the popular Astro web framework, is a new open-source framework for running AI agents inside sandboxes — isolated environments where an agent's actions can't affect the rest of your system.

**Why it matters**
As AI agents get more autonomy to write and run code on their own, sandboxing is becoming a standard safety layer. A team known for polished developer tools entering this space suggests sandboxed agents are moving from a niche security practice to a default expectation.

Source: [GitHub ↗](https://github.com/withastro/flue)
