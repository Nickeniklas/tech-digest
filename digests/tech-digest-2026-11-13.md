## Under the Hood

### LLMON: a markup language built for AI models, now in IBM's Granite 4.1

**What happened**
IBM introduced LLMON, a markup language designed for how large language models read their context. Over a long task, a model's context fills up with system prompts, past turns, retrieved documents, tool responses and output requirements; LLMON gives these parts a clear structure. It ships in Granite 4.1's 3B and 8B models.

**Why it matters**
Models often confuse instructions with data when everything is pasted together as plain text. A consistent structure for context could make small models more reliable, and could help against prompt injection, where text inside a document tries to pass itself off as instructions.

Source: [Hugging Face Blog ↗](https://huggingface.co/blog/ibm-granite/llmon-an-llm-native-markup-language-now-in-granite)

### GitHub's guide to agent skills that work in any AI tool

**What happened**
GitHub published a practical guide to agent skills: files that capture repeatable engineering work so teams can review and reuse them. Tools, project context and permissions stay specific to whichever AI host runs the skill.

**Why it matters**
Writing a process down once and running it in several AI assistants avoids lock-in to one vendor. Because skills are plain files, they can be reviewed like any other change before an agent is allowed to use them.

Source: [GitHub Blog ↗](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/)
