### Google's AI answers are cutting search traffic by 40%, report says

A new analysis says Google's AI-generated answers are reducing the traffic websites get from search by 40%, because people get their answer without clicking through. If your organisation depends on being found through Google — publishers, shops, marketing teams — this is a direct hit to how people reach you.

Source: [Revscope (via Hacker News) ↗](https://revscope.co/blog/search-seo-geo-2026/)

### GitHub and Microsoft turn AI bug reports into actual fixes

In a pilot called Codename MDASH, GitHub and Microsoft filtered thousands of raw AI-found bugs down to 99 checked, private reports — each with a suggested fix — for six widely used open-source projects. Maintainers have already fixed more than half, a contrast to AI bug-hunting efforts that buried volunteers in unverified findings.

Source: [GitHub Blog ↗](https://github.blog/open-source/maintainers/maintainers-dont-need-more-ai-bug-reports-they-need-fixes/)

### 'Java4Shell': a serious security flaw in Java

Researchers disclosed a flaw in OpenJDK, the standard version of Java, that can let attackers run their own code when a system processes Base64 data — an extremely common way of encoding information. Java runs a huge amount of business software, so expect your IT team to be patching.

Source: [Calif (via Hacker News) ↗](https://calif.io/java4shell/)

## Under the Hood

### GitHub's Agent Host Protocol lets AI sessions follow you between devices

**What happened**
GitHub built the Agent Host Protocol, an open standard that keeps an AI agent's working session available across editors, apps, phones, and the cloud. You could start a task with an agent at your desk and check on it from your phone.

**Why it matters**
Because it is open rather than tied to one product, other tools can adopt it — a step toward agent work that isn't locked inside a single app. Useful for developers building agent tooling and for teams running long agent tasks.

Source: [GitHub Blog ↗](https://github.blog/engineering/engineering-principles/building-the-agent-host-protocol-for-sessions-that-continue-across-devices/)

### Harvard study: AI coding agents moved the bottleneck to code review

**What happened**
Harvard researchers found that AI coding agents shifted where software work gets stuck: writing code is faster, but reviewing that code has become the slow step.

**Why it matters**
It echoes a pattern across the industry — the human checking step, not the writing, now limits how fast teams ship. For engineering leads, review capacity is the new thing to plan for.

Source: [ComplexDiscovery (via Hacker News) ↗](https://complexdiscovery.com/harvard-researchers-find-ai-coding-agents-shifted-the-bottleneck-to-code-review/)
