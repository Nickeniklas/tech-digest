## Chrome Has Pulled the Old uBlock Origin From Its Store

**What happened**
Google has removed every Manifest V2 extension from the Chrome Web Store — the older format a large share of browser add-ons were built on. The most visible casualty is uBlock Origin, one of the most widely installed ad and tracker blockers.

**What this means**
If a browser extension is part of how you work — blocking ads, clipping pages, managing tabs — check now whether it was built on the old format, because you can no longer install it from the store. Most popular tools have a rebuilt version under the newer format, but it is a separate listing you have to add yourself.

Source: [Webiterate ↗](https://webiterate.dev/google-removed-extensions-ublock-origin-108/)

### Cheap GPS Jammers Are Creating Navigation Dead Zones

Low-cost jammers — small devices that drown out satellite signals — have spread widely enough to knock out navigation across whole areas, the Wall Street Journal reports. That same satellite signal underpins far more than driving directions: aviation, shipping and the precise clocks behind some telecom and financial systems all lean on it.

Source: [The Wall Street Journal ↗](https://www.wsj.com/tech/gps-jammers-dead-zones-e76f3261)

## Under the Hood

### Where Open-Weight Models Stand This Summer

**What happened**
Hugging Face published its summer 2026 read on the state of open models — the ones you can download and run yourself, rather than rent through an API. It lands after an unusually dense few weeks of open releases from large labs.

**Why it matters**
Open weights decide whether an organisation can run a model on its own hardware, under its own rules about where data goes. For regulated work — legal, health, public sector — that is often the difference between being allowed to use a model at all and not.

Source: [Hugging Face ↗](https://huggingface.co/blog/state-of-open-models-summer-2026)

### Security Cameras, Repurposed as a Bird Census

**What happened**
A developer wired their existing home security cameras into BirdNET-Go, an open source tool that identifies bird species from sound alone, so the cameras now log which birds turn up in the garden and when.

**Why it matters**
It is a tidy example of the pattern behind a lot of practical AI right now: take a model somebody else already trained, point it at a feed you already have, and get a capability the hardware was never sold to do. No training run, no new equipment — it runs on the machine already in the house.

Source: [Jason Tucker ↗](https://jasontucker.blog/how-i-turned-my-security-cameras-into-an-automatic-bird-identification-system-with-birdnet-go/)
