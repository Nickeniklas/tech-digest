## NVIDIA Releases a Security Scanner for AI Agent 'Skills'

**What happened**
NVIDIA published SkillSpector, a free open-source scanner that checks the add-on 'skills' people are increasingly installing into AI agents and coding assistants — looking for malicious code, security vulnerabilities, and requests for more access than a skill should need.

**What this means**
We've covered a wave of these downloadable AI 'skills' this week — instruction packs that extend tools like Claude Code and GitHub Copilot. SkillSpector gives anyone installing one a way to check it first, the same way you'd scan a file before opening it. If your team uses AI coding tools with plugins or add-ons, it's worth running a check like this before installing anything from an unfamiliar source.

Source: [GitHub ↗](https://github.com/NVIDIA/SkillSpector)

## Quick Hits

### A Free Bundle of AI 'Employees' Covers an Entire Small Business

Agency Agents is a free, open-source collection of AI assistants, each tuned for a specific role — from writing website code to running social media accounts. It's aimed at small teams who want a ready-made set of specialists without hiring for each job.

### A Long-Trusted Backup Tool Is Trending on GitHub Again

Restic, a free open-source backup program, is back on GitHub's trending list. It encrypts your files before sending them to cloud storage like S3, Backblaze, or Google Drive — a solid option if 'set up a real backup' has been on your to-do list for a while.

Source: [GitHub ↗](https://github.com/restic/restic)

### A Free Alternative to Zendesk and Intercom Is Trending on GitHub

Chatwoot is an open-source customer support platform that combines live chat, email, and other messaging channels into one inbox. For small businesses, it's a no-subscription way to get the kind of support tools that usually come with a monthly bill per seat.

Source: [GitHub ↗](https://github.com/chatwoot/chatwoot)

### An Open-Source Framework Lets AI Systems Improve Themselves Over Time

SIA (Self Improving AI) is a free framework that lets an AI model or agent automatically refine how it performs a task, without someone manually retraining it. It's an early building block toward AI tools that get better the more they're used.

Source: [GitHub ↗](https://github.com/hexo-ai/sia)

## Under the Hood

### A New Dashboard Tracks What Your AI Coding Agents Are Actually Doing

**What happened**
AgentsView is a free, local-first analytics tool that records and visualizes sessions from AI coding agents — including Claude Code, Codex, and more than 20 others — so you can see what each one did, how long it took, and what it cost.

**Why it matters**
It bills itself as a '100x faster replacement for ccusage', a widely used Claude Code usage-tracker. For teams running several AI coding tools side by side, having one dashboard to review activity and spending makes it much easier to spot waste or unexpected behavior before it becomes a habit.

Source: [GitHub ↗](https://github.com/kenn-io/agentsview)
