## llama.cpp hits version 1.0, a milestone for AI that runs on your own computer

**What happened**
llama.cpp, the open-source software that lets AI models run on ordinary laptops and desktops instead of in the cloud, has released version 1.0. Its developers describe it as a stronger foundation for the whole local AI ecosystem.

**What this means**
Many popular 'offline AI' apps are built on top of llama.cpp, so a stable 1.0 release means those tools should get steadier and easier to trust. If you handle confidential material — client files for lawyers, student records for teachers, unreleased campaigns for marketers — running AI locally keeps that data on your own machine.

Source: [Hugging Face Blog ↗](https://huggingface.co/blog/ggml-org/llama-cpp-v1)

### Rumble-2-Flash: a tiny open speech model for 40+ languages

Hugging Face introduced Rumble-2-Flash, an open speech model that handles more than 40 languages. At just 0.5 billion parameters — a fraction of the size of today's big chatbots — it is small enough to run on modest hardware. That matters if you work with multilingual audio, from classroom recordings to interviews, and don't want to send it to the cloud.

Source: [Hugging Face Blog ↗](https://huggingface.co/blog/rumble-2-flash)

## Under the Hood

### Agent skills: write the instructions once, use them with any AI agent

**What happened**
GitHub published a practical guide to agent skills — files that capture a repeatable piece of work, such as a release checklist or a review routine, so an AI coding agent can follow it. Because skills are plain files, teams can review and reuse them like any other document.

**Why it matters**
The guide draws a clear line: the skill itself is portable across agents, while the tools, project context and permissions stay specific to whichever agent runs it. For teams, that means process knowledge stops living in one person's head or one vendor's product.

Source: [GitHub Blog ↗](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/)
