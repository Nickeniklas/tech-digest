## Old Bitly links are being hijacked

**What happened**
A report says old Bitly short links — including one in a past Burger King tweet — are being taken over so they now point to different, unintended destinations. Anyone clicking an old shortened link in an archived post could land somewhere the original author never chose.

**What this means**
If you've used short links in campaigns, newsletters, course materials or legal documents, the link still sitting in an old post may no longer go where you think. Marketers and communications teams in particular should spot-check older shortened links that are still visible to the public.

Source: [Ransom News ↗](https://ransomnews.com/burger-king-tweet-bitly-link-hijack-2026/)

## Under the Hood

### A cross-site scripting flaw in uBlock Origin

**What happened**
A security write-up describes a 'universal XSS' bug in uBlock Origin, the popular ad blocker, triggered through its element picker — the tool you use to click on and hide parts of a page. XSS means a website can get its own code to run where it shouldn't; 'universal' means the effect isn't limited to the one site that triggers it.

**Why it matters**
Browser extensions sit in a privileged position across every site you visit, so flaws in them carry more weight than an ordinary website bug. If you use uBlock Origin, keep it updated and let your browser install extension updates automatically.

Source: [iter.ca ↗](https://iter.ca/post/ubo-uxss/)

### Egyptian and Nigerian English join the Open ASR Leaderboard

**What happened**
Hugging Face's Open ASR Leaderboard, which ranks speech-recognition models (software that turns spoken audio into text), now includes Egyptian English and Nigerian English test sets.

**Why it matters**
Transcription tools often perform worse on accents they weren't trained on. Public scores for more varieties of English make it easier to see which models work well for speakers beyond the usual American and British test sets.

Source: [Hugging Face ↗](https://huggingface.co/blog/open-asr-leaderboard-liva)
