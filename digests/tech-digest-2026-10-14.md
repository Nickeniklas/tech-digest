### Ledger confirms a spy chip was behind crypto wallet thefts

Ledger, which makes hardware devices for storing cryptocurrency, confirmed that a spy implant hidden in wallets was behind thefts from its customers, BleepingComputer reports. Devices sold as the safest way to hold digital money were themselves compromised — a reminder to buy security hardware only from official sources.

Source: [BleepingComputer ↗](https://www.bleepingcomputer.com/news/security/ledger-confirms-hardware-wallet-spy-implant-behind-crypto-thefts/)

### A capable AI assistant that runs privately on your own device

Liquid AI released LFM2.5-24B-A2B, a reasoning model built to run AI agents on your own computer instead of in the cloud. It has 24 billion parameters, but only 2 billion work on any given answer, which keeps it fast. Running locally means your documents never leave your machine.

Source: [Hugging Face Blog ↗](https://huggingface.co/blog/LiquidAI/lfm25-24b-a2b)

## Under the Hood

### GitHub's AI finds leaked passwords with fewer false alarms

**What happened**
GitHub built a context-aware classifier — a model that looks at the code around a suspected password or access key, not just the string itself — for its secret scanning. It raised weighted acceptance of its alerts by 11.5% and cut the median scan time by 86%.

**Why it matters**
Security tools that cry wolf get ignored. Better precision means developers act on more real leaks, and faster scans mean leaks are caught closer to the moment they're committed.

Source: [GitHub Blog ↗](https://github.blog/ai-and-ml/githubs-model-for-secret-detection-finding-more-secrets-with-less-noise/)

### ReviewBench: an open test for AI code reviewers

**What happened**
GitHub launched ReviewBench, a benchmark for AI agents that review code. It's built on representative real pull requests (proposed code changes), with ground truth drawn from multiple sources and metrics designed to match how code review works in practice.

**Why it matters**
AI review bots are spreading fast, but there has been no shared, realistic way to compare them. An open benchmark lets teams judge which tools actually catch problems before trusting them with their codebase.

Source: [GitHub Blog ↗](https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/)
