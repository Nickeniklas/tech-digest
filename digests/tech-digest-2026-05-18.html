Lead Story

AI Agents Are Learning to Control Any Software You Already Use

A research lab released CLI-Anything, a platform that wraps any software's command-line interface in a standard format that AI agents can read and operate. It pairs with a public hub called CLI-Hub where agents can discover and control hundreds of tools end-to-end without a human in the loop.

What's requiredTechnical trainingPlain-language instructions

What this means

For most professionals, this narrows the gap between 'AI can help me think' and 'AI can do the work for me.' If your team relies on any specialized software — analytics tools, billing systems, data pipelines — CLI-Anything is designed to let an AI agent run them directly, removing the need for a technical expert to execute each step.

A Free Dashboard Now Tracks Private Jets, Spy Satellites, and Seismic Events in One Place

Shadowbroker is a new open-source intelligence platform that pulls real-time data on private aircraft, orbiting satellites, and seismic activity into a single unified interface. You can connect an AI agent to automatically scan the data and surface patterns. Tools like this previously required expensive paid subscriptions or specialist analysts.

Run AI on Your Own Computer — No Cloud Required, No Subscription

DreamServer is a new open-source platform that bundles AI chat, voice, image generation, agents, and workflow automation into a single package that runs entirely on your own machine. Nothing is sent to a server, there are no monthly fees, and it works offline. It's aimed at individuals and teams who want AI capabilities without privacy trade-offs or ongoing costs.

Open-Source Voice Agent Platform Launches for Anyone Who Wants to Build With Voice AI

Dograh launched as a free, open-source foundation for building voice-powered AI assistants and agents. Voice interfaces are spreading fast — across customer service, accessibility tools, and workplace apps — and an open platform means any team can now build one without relying on a commercial vendor's pricing or API terms.

Microsoft released a beginner-friendly, code-first course on GitHub covering how AI agents work and how to build them, across 12 structured lessons. Deep Dive

A Verified Skill Registry Solves the Trust Problem for AI Coding Agents

Tech Leads Club launched agent-skills — a curated, security-reviewed GitHub registry of reusable skills for AI coding agents including Claude Code, Cursor, Copilot, and Antigravity. Skills are validated before publication, meaning teams can extend their agents with tested instruction sets rather than pulling in unreviewed files from anywhere on the internet.

ConcernUnvalidated skillsagent-skills registry
Security reviewNoneRequired before listing
SourceAnywhere on the webCurated, community-maintained
CompatibilityUnknownTested across major agents
Trust modelCaveat emptorSigned and verified
Why it matters

As organisations deploy AI coding agents, the skills — instruction files that define agent behaviour — have quietly become a new security attack surface. A registry with a formal validation process addresses the supply-chain concern that enterprise security teams raise when permitting custom skills. Think of it as a curated app store, but for AI agent capabilities.

An AI Penetration Tester Now Reads Your Code and Attacks It — to Find Holes Before Attackers Do

Keygraph released Shannon Lite, an autonomous AI security tool that reads a web application's source code, maps likely attack paths, and executes real exploits to confirm whether vulnerabilities exist — before they ever reach production. It targets web apps and APIs specifically, and runs with full visibility into the codebase rather than probing from the outside.

DimensionTraditional pentestShannon Lite
CostHigh (specialist fees)Free / open source
FrequencyQuarterly at bestOn demand, continuous
Speed to resultsDays to weeksMinutes to hours
Code coverageScoped by contractEntire codebase
Why it matters

Traditional penetration testing is expensive and infrequent — a specialist typically visits once a quarter, scopes a specific area, and files a report weeks later. An always-available open-source tool that can scan continuously changes the economics for smaller teams and agencies. It's a similar shift to what happened when automated linters replaced manual code style reviews.
